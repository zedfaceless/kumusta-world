# Overview

As a software engineer, I am building up a set of projects that
demonstrate different languages and technologies. Before starting
larger projects, I wanted to verify that my full development
workflow is ready: writing code in VS Code, running it with Python,
tracking it with Git, and publishing it to GitHub.

This software is a small greeting program written in Python. It
prints the classic "Hello World" message and then greets the world
in a few other languages, including Tagalog, using a simple
function with a dictionary lookup.

My purpose for creating this software was to confirm my development
environment works end to end and to practice the full publish
workflow (code, documentation, video, and repository) that I will
use for future projects.

[Software Demo Video] https://www.loom.com/share/7f9ba0e65532445a8f2248996d143a09

# Development Environment

I used Visual Studio Code as my editor, Git for version control,
and GitHub for publishing the repository.

The program is written in Python 3, using basic functions,
a dictionary, and an f-string for output formatting.
